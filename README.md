**Overview**
------------

This project was a deep learning-based approach to recognizing American Sign Language (ASL) gestures. The goal was to develop a model that could classify images of ASL signs into one of 29 possible classes (26 letters of the alphabet, plus "nothing", "space", and "del").
ASL is a vital means of communication for the deaf and hard of hearing community. However, there is a significant shortage of ASL interpreters, making it difficult for individuals who rely on ASL to communicate effectively in various settings, such as education, employment, and healthcare. This project aimed to contribute to the development of automated ASL recognition systems, which can help bridge this gap and improve communication accessibility for the deaf and hard of hearing community.

**Methodology**
--------------

The project used a convolutional neural network (CNN) architecture, specifically the VGG16 model, to classify images of ASL signs. The dataset used for training and testing consisted of images of ASL signs, which were collected from various sources. The model was trained using the Adam optimizer and sparse categorical cross-entropy loss function.

**Results**
------------

The model achieved an accuracy of 98.96% on the test dataset, demonstrating its ability to effectively recognize ASL signs. The model's performance was evaluated using metrics such as accuracy, loss, and validation accuracy.
